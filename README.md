# YINGBA 润滑油客户邮箱工作台 v1.1.0

中文本地网页 + Python + SQLite，面向 Windows 10。**真实接口已实现并用本地服务测试；本人账号、真实服务和 Windows 实机尚未验收，不宣称已经能自动完成真实1000家采集。** 所有开发与检查在云端完成，没有使用您的电脑。

范围：Apollo 搜索公司 → 历史及当批去重 → 公司官网核实及商务邮箱 → 不足继续分页补搜 → Excel。没有邮件标题、正文、翻译、邮件导入或发送功能。

## 下载后使用

1. 完整解压 ZIP；首次安装 **Python 3.12 64 位**，双击 **安装.cmd**（依赖随包，按哈希离线安装）。
2. 双击 **启动.cmd**，自动打开本机中文界面。首次可以创建“模拟验收”，目标15，检查20家虚构公司得到16家合格的流程。
3. 真实运行前，在“连接状态”完成已有 Apollo API 权限的免费健康检查，以及本人 Codex 订阅的固定样本验收。需要官方 CLI 安装和本人登录；聊天插件不会自动成为本机连接。
4. 导入历史 Excel；核实全账号当日预算和本账号每页费用上界，再创建真实任务。未知费用会保存响应并暂停，需对账后继续。
5. 导出 Excel 与追溯 JSON。仅合格公司进入正式工作簿；模拟结果有明确标记。

## 已实现与实际边界

- 官方 Apollo HTTPS 公司搜索、分页、免费健康检查；成功响应没有可靠动作级实际费用时保留响应并暂停，禁止估计值冒充实扣或未知重试。
- 公开 HTTPS 网页获取、DNS/IP固定、同域跳转限制、逐页证据、保守业务和商务邮箱初筛；Codex 结构化审核后由普通代码再次核对引用和归属。
- 官方 `codex exec` 订阅桥接、严格 ChatGPT 登录检查、能力预检、本人明确运行的固定样本验收、JSON Schema/事件/文件一致性与引用校验。没有模型 API 回退，不复制认证凭据。
- 持久化队列、600秒租约、单实例、暂停跨重启、原始页响应和网页缓存、历史去重、统一有效计数、补搜与超额保留、原子Excel发布。
- 北京时间每日50分账本覆盖同一数据库全部任务。无法自动观察其它安装或应用扣费；每页必须重新核实全账号用量，并停止账本外同时支出。官方接口尚无核实到满足本需求的逐动作收费/幂等恢复凭据，所以本版不能无监督自动跑完付费1000家流程。
- 保守采用公司同域公开商务邮箱；公共邮箱、跨域关联、主体歧义、缺邮箱、不合格和未审核项均不计目标。公开来源核实不等于实际投递验证。
- Windows CMD、本人浏览器回调、真实 Apollo 账号权限/计费以及真实订阅调用仍待本机验证。真实运行权限以届时有效授权为准；本次没有付费操作或真实客户采集。

仓库公开性未改变；没有复用未提供的原型代码。源代码、脚本、离线依赖、模拟样例和测试证据均在包中。

## 开发检查

`python -m unittest discover -s tests -v`；`python -m yingba.server --no-browser`。浏览器检查需要开发环境的 Playwright/Chromium，不是用户运行依赖。完整接口调用方式见 [架构与接入](docs/架构与接入.md)、[Apollo官方接口](docs/Apollo官方接口核对.md)、[Codex订阅接口](docs/Codex订阅接口核对.md)。
