# YINGBA 润滑油客户邮箱工作台 v1.2.0

中文本地网页 + Python + SQLite，面向用户 Windows 10 电脑运行。代码、接口适配器和模拟测试已在云端实现；**Windows 实机、本人订阅、真实 Apollo 及运行时官方费用文档联网读取仍待验收**。本次未用用户电脑、未真实付费采集，也没有把模拟客户作为交付客户。

范围：取得 Apollo 公司候选 → 历史及当批去重 → 公司官网取证及 Codex 订阅语义核实 → 不足继续当前来源分页 → 导出 Excel。默认目标 1000 家合格且有可归属商务邮箱的唯一公司，整页合格结果超过目标也保留。没有邮件标题、正文、翻译、邮件导入或发送功能。

## 下载后怎样使用

1. 完整解压 ZIP，首次安装 **Python 3.12 64 位**，双击 **安装.cmd**，再双击 **启动.cmd**。Python 依赖随包按哈希安装；官方 Codex CLI 需要单独安装。
2. 先运行“模拟验收”：目标填 15，可检查 20 家虚构公司的处理、暂停恢复和导出。模拟结果有明确标记。
3. 真实核实前，按 [Codex 安装与验收说明](docs/Codex订阅接口核对.md) 完成本人 ChatGPT 登录，并在连接页运行固定样本订阅验收。公司语义核实在运行时调用该 CLI；聊天中的插件不会自动成为本机连接。
4. 先导入历史 Excel，再选择下表的一条候选来源。导出只收录有效合格公司，同时保留追溯 JSON。

| 候选来源 | 需要什么 | 分页和费用边界 |
| --- | --- | --- |
| 已保存的 Apollo 公司 | 已有 Apollo API 权限、本人订阅验收 | 官方固定只读端点；当天先取得费用证据，经 Codex 辅助评估和代码确认免费后连续分页。不占用收费预算，不做付费对账；不会转全库搜索 |

## v1.2.0 的实际行为

收费搜索先原子占用单页已核实上界。响应完整、请求一致且代码校验通过后，状态为“已验证响应，待核实实扣”，可以继续同日已授权批次；**实际扣费保持空值，预留不冒充实扣**。批次结束后或跨日前核实费用。本人逐项核实所选动作的实扣相同，才可一次批量对账；未知结果不在该批量范围内。

北京时间每日 50 分上限覆盖同一数据目录内全部任务。程序不能观察其它电脑、应用或人员的扣费，因此收费授权需要已知全账号用量，并确认执行期间没有账本外支出。未知结果立即冻结新的收费请求；跨日未结响应、授权过期、预计超限或证据不明也会暂停。已有旧缓存可恢复；缺少新授权的旧任务不会继续发起收费，需暂停后续期授权。

公司资格必须同时通过普通代码初筛、运行时 Codex 语义审核和引用/邮箱归属校验。候选、缺邮箱、主体或业务不明、未审核项不计目标。保守采用公司同域公开商务邮箱；公开来源核实不等于实际投递验证。

官方订阅桥接使用 ChatGPT 登录，不回退付费模型 API、不购买额度、不复制认证文件。本人浏览器登录、Windows 原生沙箱、真实账户权限/收费和取证效果尚待本机验证。本轮云环境的官方费用文档直接联网读取未贯通；相关流程以本地服务和模拟证据测试，不能称为已跑通真实免费或收费采集。

仓库公开性未改变，没有复用未提供的原型代码。源代码、启动脚本、锁定依赖、说明及明确标记的模拟样例随包交付；实际测试结果以本轮报告为准。[第二轮报告](docs/第二轮验收报告.md) 保留为历史记录。

## 开发检查

`python -m unittest discover -s tests -v`；`python -m yingba.server --no-browser`。浏览器自动检查使用开发环境的 Playwright/Chromium，不是用户运行依赖。官方接口和边界见 [Apollo 核对](docs/Apollo官方接口核对.md)、[Codex 核对](docs/Codex订阅接口核对.md)。
