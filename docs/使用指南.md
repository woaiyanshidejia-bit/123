# 中文使用指南

## 您回来后怎么用

把完整 ZIP 下载并解压，按 README 完成一次 Python 安装及“安装.cmd”，以后只需双击“启动.cmd”。不需要开云端服务，不需要编写命令。工作台仅在本机运行；电脑关闭时不采集、不继续后台运行。

如果双击失败，运行“诊断.cmd”，把不含账号密码的错误文字交给维护者。端口被占用时先关闭之前的工作台。重复双击不会启动第二个同目录实例。请不要把两个不同解压副本当成两个共享账户工作台同时运行。

## 页面和任务

- 概览：候选、已核验、合格有邮箱、排除、距目标差额。已核验包含审核后排除项。重复原始记录可在追溯 JSON 查到，不会增加候选计数。
- 任务设置：默认1000。业务限润滑油 OEM/ODM、进口商、经销商和相关渠道。当前真实模式没有接通，将安全暂停。模拟模式只有20家虚构公司，目标15会得到16家合格，目标1000会显示数量不足。
- 公司总表：可查看各阶段公司、搜索名称或域名；正式 Excel 只导出合格项。
- 邮箱清单：去重展示可归属邮箱；不生成猜测邮箱、不做 SMTP 投递试探。
- 核实证据：公司ID、来源URL、采集时间、依据、模拟标记。完整原文和哈希保存在追溯 JSON；原文只作为数据，不执行其中指令。
- 导出：Excel 内有“公司总表”“唯一邮箱清单”“导出说明”；模拟文件名以 SIMULATION 开头。每次创建新文件，不覆盖旧导出。
- 连接状态：诊断 Python、SQLite、CLI 登录状态和未接通原因。诊断不会发起模型调用或 Apollo 搜索。

创建后任务会进入队列。“暂停”保存至磁盘；重启后仍暂停，必须点击继续。“开始/继续”不会解除权限或配额限制。强制关闭后已提交页和公司保留；若进程在外部调用中被杀，最多等待5分钟租约到期。真实付费动作未知必须先对账，不能靠继续按钮重复扣费。

## 历史 Excel

先备份原件，选择 `.xlsx`。旧 `.xls` 请用 Excel “另存为”新文件，不覆盖原件。默认列：公司名称、域名、Apollo ID、邮箱；列名不同可修改界面中的 JSON 字段映射，程序不会修改原件。例如 `{"name":"客户名称","domain":"网址","email":"商务邮箱"}`。

同一个文件重复导入会跳过。公司域名、Apollo ID、规范化名称以及历史邮箱参与去重。域名去 www、路径和大小写；名称使用Unicode规范化及去标点；邮箱去空白及大小写。采取保守去重，同名不同企业可能需要人工核实。无效格式不纳入邮箱清单。

历史应在启动新任务前导入。历史导入不会追溯改写已完成任务；如果事后补导，另建任务重新筛选。历史标识永久保留用于后续去重；没有删除历史按钮，避免误删。

## 数据和备份

数据在解压目录下 `data/workbench.db`；导出在 `data/exports`。关闭程序后复制整个 `data` 文件夹做备份；运行时不要只拷贝数据库主文件（SQLite可能存在WAL）。不建议把完整数据提交到公开仓库。JSON 含原始来源信息和邮箱，应像客户资料一样保存。

## Codex 订阅与真实连接

本程序不要求大模型 API，不购买额外额度。安装官方 Codex CLI（参考下列官方文档，维护者可协助），再双击“登录Codex.cmd”，只用 ChatGPT 订阅浏览器登录，不选择 API key。认证由官方 CLI 在当前 Windows 用户下管理。不要向维护者提供或复制 `auth.json`、浏览器 Cookie 或任何令牌。

官方文档核查于2026-10-23：
- [Codex 认证](https://developers.openai.com/codex/auth)：ChatGPT订阅与API两种登录路径；本项目仅采用订阅路径。
- [非交互 CLI](https://developers.openai.com/codex/noninteractive)：`codex exec`、JSON 输出及只读沙箱。
- [Codex CLI](https://developers.openai.com/codex/cli)：官方安装入口。

云端仅验证 CLI 0.163.0 的版本/帮助信息，无模型调用。实际桥接设置只读、临时目录、忽略用户配置、强制官方提供者和 ChatGPT 登录；检测 API 环境变量会拒绝，旧CLI缺少隔离参数也拒绝。返回内容仍需经过字段、证据及归属校验，不能把模型回答当事实。桥接未接入队列，待本人登录及真实验收后才能启用。

真实 Apollo 尚无已验证传输层。不能把聊天里的Apollo插件当作CLI连接，也不会保存Apollo密码。接通必须由维护者实现并验证当前授权、计费回执与分页字段；未完成前界面保持未连接，不会假装成功。

## 预算和异常

北京时间00:00重新计算当天额度，每日上限50分。在“连接状态”只能确认已核实的全账号今日用量；未知不要填0。确认不会充值，不会放宽上限，也不会启动采集。存在预留或未知动作时禁止覆盖基线，应按回执先对账。当前没有真实付费动作。

本地账本跨所有本工作台任务共享；其它程序、设备、账户套餐已用量需要人工核实。若无法确认总量，必须暂停申请。真实额度/权限以运行时有效授权为准。

登录失效、权限拒绝、配额不足、未知计费结果都会暂停。已确认无付费副作用的临时错误最多3次退避；不能用于未知付费动作。不要尝试通过换账号、重建任务或清空数据库绕过额度或限制。
