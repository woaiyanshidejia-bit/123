# 中文使用指南（v1.2.0）

## 第一次打开

云端开发不需要用户电脑开机。回来后下载完整 ZIP，解压到本人可写文件夹，例如 `D:\YINGBA`。安装 Python 3.12 64 位，勾选添加到 PATH 或安装 Launcher；双击“安装.cmd”，再双击“启动.cmd”。以后只需启动脚本。工作台仅监听本机，关闭启动窗口或电脑关机后停止运行。

安装脚本使用随包 wheel 和哈希安装 Python 依赖，不安装模型、不购买服务。官方 Codex CLI 需另行安装。失败时双击“诊断.cmd”，提供错误文字和任务 ID，不提供密钥、Cookie 或认证文件。同一数据目录重复启动会被阻止；不同解压副本不会自动共用账本，同一账号不要同时在多个副本采集。

## 先运行无需账号的模拟任务

任务设置中选择“模拟验收”，目标填 15，创建并开始。20 家虚构公司、22 条原始记录最终有 16 家合格、4 家排除，超额结果保留。目标填 1000 时会显示数量不足。可测试暂停、关闭窗口、重启后仍暂停、继续和导出。

模拟文件名以 `SIMULATION_` 开头，工作簿也有说明。模拟数据不能作为真实历史表导入，不会占用真实公司的去重身份。模拟通过不表示 Windows 或真实服务已经验收。

## 真实任务共用的准备

1. 先导入历史 Excel，用于排除已处理公司；历史表与“候选导入文件”用途不同，见后文。
2. 按 [Codex 官方接口核对](Codex订阅接口核对.md) 安装官方 CLI，双击“登录Codex.cmd”，本人浏览器使用 ChatGPT 登录。不选择 API 登录，不复制认证文件。
3. 在“连接状态”勾选本人同意，点击“运行订阅最小验收”。它会用现有订阅额度处理固定虚构材料，不访问客户网站、不消费 Apollo 积分、不购买服务。只有登录方式、CLI 能力、结果格式和引用都通过才接受；记录 24 小时有效，版本变化或审核异常需要重新验收。
4. 根据下面三条来源路径创建任务。默认目标 1000；只有已核实、有可归属商务邮箱的唯一公司计入目标。

固定样本通过不等于真实业务判断、费用信息或全部工具隔离已验证。运行时仍逐条调用本人 Codex CLI 审核公司主体、润滑油业务与邮箱依据。程序以代码控制抓取、预算和队列；模型不能直接调用 Apollo、购买服务或放行收费。

## 路径一：读取已保存的 Apollo 公司

适合账号中已经保存有目标公司。连接状态填写已有 Apollo API key 和账号备注，勾选本次授权，点击“连接并免费检查”。密钥只留在当前进程内存，输入框立即清空；关闭程序后需重新输入。免费健康检查只证明该检查成功，不证明其它接口权限已通过。

新建任务选择“已保存的 Apollo 公司”。公司名称条件是名称包含筛选，不是润滑油业务关键词；可以留空读取已保存公司，也可填写 Apollo 公司列表 ID。每页最多 100 家，账号备注必须与连接一致。

开始前程序取得该固定只读接口的官方费用说明，用 Codex 辅助解释，并由代码确认免费。当天相同账号、固定条件的有效评估可以复用，跨北京时间日期重新评估。此路径不需要填写收费预算基线，不预留收费积分，也不做付费对账；它仍需要有效 API 权限、网络和订阅额度。

证据获取失败、费用含义不明、登录或权限失效时暂停，不把未知当免费。来源耗尽会显示不足；不会自动切换全库收费搜索、保存新公司或调用收费补全。公开说明和本地测试不代表用户账号上的真实免费运行已经验收。

## 路径二：导入已有 Apollo CSV / XLSX

在任务设置的“已有 Apollo 候选文件”选择文件，填写原始 Apollo 列表、搜索或导出来源链接，确认来源声明，再点“导入并创建核实任务”。导入不需要 Apollo API key，不调用 Apollo。**文件在 Apollo 中导出是否收费，要在 Apollo 界面另行核实；工作台不代为导出。**

通常自动识别公司名称、官网等列；无法识别时修改字段映射。文件最大 10MB、10 万行，支持 `.csv` 和 `.xlsx`。CSV 使用 UTF-8，或带 BOM 的 UTF-16；编码不符时另存副本，不覆盖原件。

程序保存原始文件、内容哈希、来源声明、映射和逐行原文。来源声明不是在线认证。表中邮箱只作为原始信息，不能直接成为合格邮箱；还要官网取证、运行时 Codex 语义审核和代码归属校验。

原文件分页完成且任务停止后，数量不足可用“补充到当前导入任务”追加另一份已有文件。不能向正在读取原文件的任务追加，也不会自动改用收费 API。

## 路径三：按当日授权连续搜索 Apollo 全库

先完成 Apollo 连接、订阅验收，并在连接页核实北京时间当天**全账号已用量**。未知时留空；不要把账期总量或余额当作今日已用量，不要把未知填写为 0。

新建任务选择“Apollo 全库公司搜索”，填写固定关键词、地区、每页数量和账号备注。当前自动连续分页只支持能够核实为**现行、非旧版套餐，每页最高 1 积分且无附加收费**的情形。不同套餐或不明确的费率保持暂停，不能用手填估算代替核实。

填写本人账户显示的套餐名称、费用说明页面链接和相关原文，不粘贴密钥。逐项确认现行计费、执行期间无账本外支出，以及本日在 50 分上限内按固定条件连续分页的授权，点击“用Codex评估并授权今日搜索”。程序读取官方端点说明和价格说明，结合账户原文让 Codex 解释，再由普通代码核对端点、套餐、每页上界、来源和授权。模型判断不能独自证明费用，也不能自动把未知归零。

评估通过后再“创建并开始”。授权绑定账号、北京时间日期、固定筛选和每页数量，仅页码可以向后推进。换条件需要重新评估并新建任务。旧任务没有有效费用授权、跨日或授权撤销时，先暂停并等待在途请求结束，再点“为当前暂停任务续期授权”；续期沿用该任务原条件，不会借此改写旧请求。旧任务的已结算缓存仍可恢复，不会因为升级再次收费。

## 收费预算、连续分页和对账

北京时间每日上限 50 分，同一数据目录的全部任务共用账本。程序不能观察其它电脑、软件或人员的扣费，所以已核实用量和“执行期间无账本外支出”声明是收费运行的必要条件。确认基线不是充值，也不会提高上限。

每次发送前原子占用已核实的单页上界，并保存请求指纹。服务器响应完整且与请求相符、代码校验通过后，进入“已验证响应，待核实实扣”；可处理候选并继续同日已授权分页。这个状态的**实际扣费仍为空**，整页上界继续计入占用，不会先写成 1 分实扣。已用量 + 未结上界 + 下一页上界超过 50 时暂停。

成功响应本身不是实扣账单。请在批次结束后或跨日前核实实际费用。提供实际扣费、北京时间归属日和核对依据后，可逐项保存；如果本人已经逐项核实同一授权、同一发生日的所选动作实扣完全相同，也可选择这些“已验证响应，待核实实扣”动作一次批量对账。批量提交是一次事务，有一项不合格整批不改；不能根据统一标价、总额平均或费用上界替各动作推定实扣。

网络/响应结果未知立即冻结新的收费请求；未知结果、不同授权/发生日或未验证响应不能混入批量对账。若响应已保存，核账后使用原响应，不重复请求。若响应丢失，只能核清账目并保留原动作，程序不盲目重发。仍有在途请求时不能结算缺失响应。

跨日未结动作需先核实实际费用和归属日；未结动作也阻止覆盖用量基线或新建收费授权。结清后核实今日全账号用量，必要时续期授权再继续。实扣超过已核实上界会使原费用假设失效，须重新核查，不会通过换日、新建任务或删除数据库放行。免费读取和本地导入不走收费账本，也不会清除旧付费风险记录。

## 公司核实、数量不足和导出

程序先处理当前页全部候选，再判断目标，不足继续当前来源下一页。Apollo 两种在线来源各受已核对接口的 500 页范围限制；文件导入按原文件分页，另有程序安全上限。来源耗尽、连续 3 页没有新增等会明确停止或暂停，不会假装达标。扩大范围时另建固定条件任务，历史及既有真实身份仍参与去重。

合格要求：主体和润滑油 OEM/ODM、进口、经销或相关渠道业务有依据，运行时订阅审核通过，公开商务邮箱完整出现在当前公司的对应网页且属于该公司域名。模型结论必须与普通代码初筛相交。招聘、隐私、退订、自动回复、公共邮箱、跨域归属不明或主体歧义等不计目标。公开来源核实不等于实际投递验证。

历史排除名单支持 `.xlsx`，最大 10MB、10 万行；`.xls` 请另存新文件。默认列为公司名称、域名、Apollo ID、邮箱，可修改映射，例如 `{"name":"客户名称","domain":"官网","email":"商务邮箱"}`。程序只读原件，按文件内容和映射识别重复导入，修正映射后可补导同一原件。

域名、Apollo ID、规范化名称及邮箱用于保守去重；同名异企也可能排除，原始行和原因保留。事后导入历史会重算受影响任务；已下载的旧 Excel 不自动修改，需重新导出。

公司总表界面显示全部阶段；正式工作簿只含有效合格公司的公司总表、唯一邮箱清单和导出说明，保存 URL、采集 UTC 时间及依据。追溯 JSON 含原始记录、排除原因、逐页证据和哈希。每次生成新文件，不覆盖旧导出；逐格回读核对，并防止外部文本成为 Excel 公式。

## 暂停、恢复和备份

暂停跨重启保留。强制中断后，已提交候选、原始响应、网页证据和导入文件继续使用；旧任务租约可能需要最多 10 分钟到期。只有明确无付费副作用的暂时错误允许有限退避；未知收费、登录、权限和订阅限额不会被“继续”按钮绕过。

数据在 `data/workbench.db`，导出在 `data/exports`。关闭程序后复制整个 `data` 目录备份；运行时不要只拷贝数据库主文件。升级前先备份，v1.2.0 迁移保留原任务和历史；只有缓存和原始记录不意味着旧任务自动获得新的收费授权。旧任务缺少固定搜索设置时需新建任务，旧记录仍保留。

真实服务仍需本机验收：Windows 启动和沙箱、本人登录、运行时官方费用文档联网读取、Apollo 权限/实扣依据、官网取证与语义审核质量。本轮云端没有跑通用户真实账户，费用文档的直接联网读取也未贯通；本地模拟测试不能替代这些检查。不要将客户资料、`data` 或认证文件上传公开仓库。
