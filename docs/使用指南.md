# 中文使用指南（v1.1.0）

## 第一次打开

今晚无需开机。回来后下载完整ZIP，解压到本人可写文件夹，例如 `D:\YINGBA`。安装 Python 3.12 64位，勾选添加到 PATH 或安装 Launcher；双击“安装.cmd”，再双击“启动.cmd”。以后只需启动脚本。程序仅监听本机，关掉启动窗口即停止；电脑关机时不运行。

安装脚本只使用随包 wheel 和哈希，不联网安装模型或购买服务。失败时双击“诊断.cmd”，提供错误文字即可，不要提供密钥、Cookie或认证文件。同一数据目录重复启动会阻止；不同解压副本不会自动共用账本，禁止同时用于同一账号采集。

## 先做一个无需账号的模拟任务

进入任务设置，模式选“模拟验收”，目标15，创建并开始。20家虚构公司、22条原始记录中16家合格、4家排除；结果保留超额。目标1000会显示数量不足，绝不会假装完成。可测试暂停、关闭窗口、重启后仍暂停、继续和导出。

示例文件名以 `SIMULATION_` 开头，工作簿内也有模拟说明。模拟数据不能作为真实历史表导入，不会占用真实公司的去重身份。

## 本人真实连接

需要已有 Apollo API 权限，以及可正常使用的 ChatGPT Codex 订阅。没有相应账号权限时保持暂停，程序不会购买或绕过限制。

1. 安装官方 Codex CLI，详见 [官方接口核对与安装](Codex订阅接口核对.md)。双击“登录Codex.cmd”，本人浏览器用 ChatGPT 登录。不要选择 API 登录或复制认证文件。
2. 在“连接状态”勾选本人同意，点击“运行订阅最小验收”。这会使用订阅额度审核固定虚构材料；不访问客户网站、不消费Apollo积分。只有登录类型、CLI能力、完整结构化结果及引用均通过才接受；验收记录24小时有效，版本变更或审核异常需重验。它不是全部工具隔离或业务准确率的证明。
3. 输入已有 Apollo API 密钥和账号备注，勾选授权，点击“连接并免费检查”。密钥仅在当前进程内存，输入框立即清空；重启需重新输入。健康通过不等于搜索权限/计费验收通过。断开按钮清除连接。
4. 核实本账号套餐、积分单位、单页费用上界和北京时间当天全账号使用量。不要猜测、不要把未知写0。费用上界未知时任务会在搜索前暂停。

CLI缺少所需官方参数、沙箱/权限不支持、订阅受限、Apollo权限拒绝等都必须处理具体原因后再验收，不能靠“继续”绕过。本次云端没有执行这四步的真实服务调用。

## 正式任务

先导入历史表，再创建任务。默认目标1000；关键词默认 `lubricants`，可填英文关键词和地区，每页最多100家公司。账号备注必须和连接一致。搜索设置创建后不可改，保证已付费动作可恢复；需要扩大条件时另建任务，已有历史和真实身份仍参与去重。

队列先处理当前页全部候选，再检查合格数；不足继续下一页，超额保留。来源耗尽、500页上限、连续3页无新增都会明确停止/暂停，不会显示达标。当前关键词不穷尽全部市场；不足时可用不同条件另建任务。

合格要求：主体和润滑油OEM/ODM、进口、经销或相关渠道业务有依据，订阅审核完成，公开商务邮箱完整出现在该公司的对应网页证据且属于其域名。普通代码的主体/业务初筛和商务邮箱过滤不能被模型覆盖。隐私、招聘、退订、自动回复等地址过滤；跨域/公共邮箱或歧义主体暂不纳入。公开来源不等于实际投递验证。

## 每页预算和对账

北京时间每日上限50分，全部任务共享同一账本。程序不能自动得知其它软件或设备的支出，因此每页都需要核实全账号基线，并保证执行期间没有账本外扣费。检查后在连接状态填写已用分数、勾选确认；这是记录基线，不是充值，也不会提高上限。

Apollo没有已核实的逐动作实扣回执接口。程序先原子预留费用上界、记录未知动作，再最多请求一次；即使收到公司列表，也先保存响应并暂停。待您从服务商核实实际扣费、北京时间归属日和动作专属依据后，在“未知付费动作”填写对账。**预计费用不能代替实扣，账期总额不能代替今日总额。**

对账后重新核实今日用量，回概览继续；已保存页从数据库读取，不重复请求。若响应未保存即断线/崩溃，只能核清账目，原动作禁止盲重发。请求仍在途时不能结算缺失响应。跨日未知动作持续冻结，不能通过换日期、新建任务或删除数据库绕过。

这项计费边界意味着当前不能无人看管自动完成1000家付费流程。需要先在有效授权下验收真实计费来源，不能把它描述成“只欠登录”。

## 历史Excel与导出

支持 `.xlsx`，最大10MB、10万行；`.xls` 请另存新文件，不覆盖原件。默认列名为公司名称、域名、Apollo ID、邮箱。列名不同可改映射，例如 `{"name":"客户名称","domain":"官网","email":"商务邮箱"}`。只读原件，按内容和映射识别重复导入；修正映射后可补导同一原件。

域名、Apollo ID、规范化名称、邮箱用于保守去重；同名异企可能被排除。重复记录及原因保存在追溯JSON，不会伪增合格数。事后导入历史会重新排除已存在的重复公司并重算完成状态、暂停受影响任务；之前已下载的Excel不自动改写，需要重新导出。

公司总表可查看全部阶段；邮箱清单和正式Excel只显示有效合格公司的邮箱。Excel包括公司总表、唯一邮箱清单、导出说明；来源URL、采集UTC及依据均保留。JSON含原始Apollo记录、排除原因、逐页证据正文/哈希、待审核网页缓存。每次导出新文件，不覆盖旧导出，写入后逐格回读核对且阻止公式注入。

## 暂停、恢复和备份

暂停状态跨重启保留。强制中断后，已提交页、候选、对账响应和网页证据继续使用；旧租约最多等待10分钟到期。权限/额度/未知计费错误保持暂停，不自动重试。仅明确没有付费副作用的暂时错误允许最多3次退避。

数据位于 `data/workbench.db`，导出位于 `data/exports`。关闭程序后复制整个data目录备份；运行时不要只拷贝数据库主文件。升级前备份；v1.1.0能迁移v1数据，未知旧付费动作没有请求指纹时不会伪绑定恢复。不要将客户资料、data或认证文件上传公开仓库。
