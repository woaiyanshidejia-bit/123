# 架构与接入边界

## 持久化与执行

SQLite WAL + BEGIN IMMEDIATE，任务分页及整页入库在同一事务提交；核实结果、证据、邮箱与阶段在同一事务提交。跨进程 task owner/300秒租约保护认领；内核文件锁保护单实例。暂停在提交前重新检查状态，不能把暂停期间的请求结果提交为成功。

中断后候选继续核实，已提交分页不回退；失效租约自动到期。程序正常关闭不改写暂停状态。临时错误使用持久化 attempts/next_at 最多3次退避，异常不写原始报错以避免泄密。schema为首版，不支持跨版本迁移；将来升级必须先备份并引入版本迁移。

阶段：candidate → qualified / excluded；原始重复记录另存raw_records。身份索引跨任务保留domain/apollo/name/history-email，冲突时保守跳过，别名键补绑定到已命中身份。去重规则会保守合并同名公司，不能作为工商主体识别的替代。

## Source 接口

`search(page) -> (records, exhausted)`：页号从1开始；record包含name/domain/apollo_id。`verify(record) -> dict`：主体确认、业务确认、允许类别、同域公开URL、依据、来源原文及原文中出现的邮箱。结果必须与任务模式一致。未来适配器必须验证source来源与网页取证链，不能让任意AI输出直接设置确认标志。

生产适配器须处理安全公网获取（禁止私网/回环/元数据地址，逐重定向检查，DNS重绑定防护、超时、体积限制）；本版不提供通用URL抓取器，也没有接收任意URL后代用户访问的接口。第三方目录/公共邮箱若需支持，必须新增显式可归属证据规则；当前同域策略偏保守。

不可信网页中的命令不执行、不传给shell；界面用textContent显示，Excel对公式前缀转义。证据按company外键保存，邮箱外键和联表再次校验company一致。原文及SHA256导出用于复核，不代表来源真实性或投递能力保证。

## 付费传输接口

`PaidGateway`只接收由维护者验收后的transport，不包含网络Apollo实现。执行顺序：全账号已知基线 → 原子预留action → 持久化unknown → transport一次 → 明确回执actual结算。结果未知永不重试。同action再次执行永远拒绝；应凭服务商外部回执对账，不能靠新action绕过。

进程在reserve后、unknown前死亡：保留reserved占用，重启不得重发同action，人工对账。跨日未结算动作仍占用或阻断；新日无基线必须暂停。实际大于估计冻结该日基线并申请复核。`Receipt`里的计费单位必须与账户50分单位一致；未验证价格或计费单位不得启用。

Apollo任何可能付费动作必须经过该网关，包括搜索、补搜、解锁和增强；动作ID必须由账户/任务/查询指纹/页号持久决定，不得每次随机生成。分页回执应持久化并与页提交做恢复对账。本版生产连接因此保持关闭。TransientError仅允许确定未发生付费的操作。

## Codex

官方订阅登录由`codex login`完成。`CodexSubscription.status`只做只读登录类型诊断，不复制认证、不输出原始状态。`evaluate`是显式启用的桥接代码，不由UI/任务引擎调用；CLI配置隔离和订阅类型检查通过后才可能执行，失败不回退API。云端仅mock验证命令和拒绝路径，不消耗用户订阅去做实调用。

模型接口不能自行调用Apollo、更改预算、发送邮件或决定是否绕过权限。正式核实需独立来源证据校验。未实现验证过的结构化模型结果→Source桥接；不能把“已登录”误当“真实工作流已连接”。

## 运维与限制

仅监听127.0.0.1，Host白名单 + 每次启动随机CSRF令牌 + Origin检查。无外部CDN、无第三方前端依赖、无CORS授权。此处是个人电脑本地应用，不是多用户服务器。运行目录须本人可写，恶意本地进程不属于隔离边界。

导出完整数据到JSON，数据库/原始网页可含客户资料，不包含应用认证配置。打包只选源码、离线依赖、说明、测试证据和显式模拟样例，排除data、.git、认证文件、日志和临时用户文件。
