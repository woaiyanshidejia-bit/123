# 架构与接口（v1.1.0）

## 调用链与职责

`server.serve` → `Engine(source_factory=Runtime.source_for_task)` → 模拟Source或真实`RealSource`。真实搜索固定调用`ApolloClient`，核实固定调用`PublicVerifier`与`CodexSubscription.review_company`；普通代码控制任务、预算、状态与验收。模型不能改预算、直接调用Apollo或决定继续付费。

真实任务创建时，搜索筛选、每页数量、费用上界和账号备注与task一起事务保存至`task_settings`。密钥不在设置中，只存在Runtime当前进程的Apollo客户端。动作ID为`apollo:{task_id}:page:{page}`，请求包含固定endpoint、账号备注和查询；PaidGateway另保存请求指纹，防相同动作替换请求。

```python
from yingba.db import Store
from yingba.runtime import Runtime, settings
from yingba.engine import Engine
store = Store('data/workbench.db')
runtime = Runtime(store)
engine = Engine(store, source_factory=runtime.source_for_task)
# UI负责本人显式连接、订阅验收、预算基线确认；以下仅创建固定设置。
task = engine.create(1000, 'real', config=settings({
    'filters': {'q_organization_keyword_tags': ['lubricants']},
    'per_page': 100, 'estimate_points': None,
    'account_label': '本机唯一Apollo账号'}))
# 未知费用上界/连接未验收时step安全暂停，不执行付费请求。
engine.step(task)
```

## 持久化与恢复

SQLite WAL、FULL同步和BEGIN IMMEDIATE事务。分页与整页入库一起提交；证据、邮箱、审核阶段一起提交。任务owner/600秒租约防重复认领，足够覆盖每条最多3×30秒网页、CLI只读预检及180秒订阅调用；所有外部调用都有上限。内核文件锁限制同一数据目录单实例。

暂停提交前重新检查owner、状态和租约；旧worker不能暂停新owner。中断后的候选、网页缓存、已对账Apollo响应可复用。需要等待旧租约到期时最多10分钟。有限退避只用于明确无付费副作用的TransientError，最多3次；未知付费状态不适用重试。

schema version 2兼容v1数据：已知历史回执迁入请求指纹，未知旧动作不伪造请求绑定；新版数据库拒绝被旧版本降级改写。历史映射在导入事务中迁移。升级前须备份完整data。

原始数据与去重：`raw_records`保留当批及重复原始行；domain/Apollo ID/name/email身份全局去重，模拟命名空间独立，历史跨任务生效。弱名称冲突不向旧实体传播新域名，防污染。公司阶段candidate → qualified/excluded；已抓取而未审核页面在`verification_cache`持久化，暂停不丢取证原文。

## 真实网页与订阅核实

`PublicFetcher`只访问候选公司同域HTTPS，验证全部DNS地址为公网，固定选定IP并校验TLS证书，每次跳转重验，不带Cookie或认证。DNS10秒、每页30秒总期限、150KB、最多3页；有总截止关闭连接的watchdog，慢响应头不能无限阻塞。403/429直接暂停，不绕过访问限制。

`PublicVerifier`只进行保守初筛，返回`review_required=True`及逐页`evidence_pages`。不执行JavaScript，不猜路径或邮箱。主体、业务关键词上下文和商务邮箱过滤后仍须Codex结构化审核；最终必须与代码初筛相交。仅有模型断言或引用字符串不足以越过代码审核。

CLI为官方`codex exec`，强制openai/chatgpt，忽略用户配置和规则，临时目录，只读沙箱，关闭已核对的shell/web/apps/MCP等能力。`preflight`只读探测；`validate_local`需本人明确授权固定合成材料调用，绑定CLI版本和24小时验收记录；`review_company`验证Schema、JSONL完成事件、结果文件一致、公司域名与逐字引用。异常使旧验收失效。无任意prompt执行入口，无API回退。官方没有已核实的全部工具封闭保证，验收不等于该保证。

Runtime将每个邮箱与PublicVerifier同页商务邮箱集合求交；Engine再次验证同域URL、原文完整邮箱与公司外键，防串数据。正式计数和Excel共用`QUALIFIED_ROWS`。保守只支持公司同域公开邮箱；跨域、个人公共邮箱、JS渲染、验证码、第三方目录等不自动合格。

## 预算与已保存响应

`PaidGateway.execute`将预算预留、请求指纹和unknown标记在发送前原子保存。响应为`Observation`时只保存，不造费用回执；`reconcile_captured(action, actual_points, billed_day, external_reference)`在核实后原子结算并发布缓存。同请求再次执行只读缓存；不同请求复用动作、重复账单号、响应篡改、跨日未核实均拒绝。

真实发送前固定同一个已确认客户端并复核账号与日期，避免切换账号或跨午夜使用旧基线。每次发送清除当日确认状态，下一页须重新确认全账号基线。缺失响应对账须无在途任务租约，并在同一事务检查、结算、记审计；不恢复未知响应，不重发原动作。

50分限制仅能可靠约束同一SQLite内全部任务；不能自动观察其它程序、安装或设备的支出。官方Apollo账期余额不是北京时间日账本，HTTP请求ID不是实际收费回执。因暂无已核实的逐动作收费与幂等恢复接口，真实运行需要每页人工核实，不能无监督完成1000家付费采集。当前没有自动加额度或购买入口。

## 本机安全与交付

仅监听127.0.0.1；精确Host、Origin和启动随机CSRF令牌；无外部前端资源。网页数据通过textContent渲染，Excel全部外部文本防公式注入并逐格回读，导出原子发布。凭据不写日志、数据库或交付包。恶意本地进程和恶意改写数据库不属于个人应用隔离边界。

包只允许源码、说明、离线wheel、测试证据与明确模拟样例；排除data、凭据、验收receipt、.git和临时文件。CLI安装、本人登录、真实服务、Windows实机仍须本机验收，参见对应官方接口核对文档。
