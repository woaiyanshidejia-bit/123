# YINGBA v1.1.0 第二轮工程审核

本报告对应云端交付，所有公司均为合成测试，真实付费Apollo、真实模型调用、用户电脑和本人浏览器均未使用。第一版确有真实适配器未接入、弱网页判定和账单恢复不足，本轮已继续实现，不能把第一版模拟贯通当作全部完成。

以上均有实际实现，不需要用户补写适配器代码。运行时没有满足真实连接/验收/计费条件就暂停；没有NotImplemented冒充成功。`Disconnected`仅保留作未配置引擎的安全默认，正式server使用Runtime。

## 本轮修复的主要问题

1. Apollo真实HTTP及分页接入队列，固定任务设置和请求指纹；未知费用成功响应也保存且暂停，人工对账后只读缓存。
2. 原先公司名提及+分散关键词容易误判，改为保守主体/同句业务初筛、隐藏和否定上下文过滤、Codex语义审核、普通代码再次求交。邮箱排除privacy/hr/noreply等，模型不能重新引入；邮箱必须完整在对应网页原文出现。
3. 证据逐页绑定邮箱与公司；暂停前已取网页缓存持久化，JSON保留未审核原文。统计和Excel统一有效证据查询，公开来源不冒称投递验证。
4. 模拟身份与真实隔离；弱名称匹配不扩散新域名；同文件更正历史映射可补导。事后历史导入重算已有公司与完成状态，邮箱清单同步剔除。
5. 请求和unknown原子持久化、回执唯一性、响应哈希、旧库迁移、跨日实扣、并发预算及崩溃恢复；未知动作不盲重试。
6. 独立集成审查发现并复现账号切换、跨午夜发送、模型覆盖商务邮箱过滤、在途缺失响应被提前结算、UI旧邮箱残留，全部修复并加测试。
7. 600秒租约覆盖有界网页和CLI执行；旧owner失败不能干扰新owner。网页总时限定时关闭连接，防慢响应头无限拖延；重复无进展分页暂停。
8. Excel全外部字段公式注入防护、逐格回读和原子发布；历史文件大小/ZIP展开限制；错误消息不泄漏密钥。
9. Windows脚本关闭DelayedExpansion、正确pushd/失败门控、兼容Python查找、Codex npm shim返回和退出码，依赖增加SHA256强制离线校验。

## 不可夸大的验收边界

全量测试和浏览器/包检查数字见 [测试报告](测试报告.md)，逐项输出在artifacts。模拟20家公司得到16家合格；另有目标1000保留1005家虚构合格公司的规模测试，均不是客户名单。

Codex使用官方订阅路径，禁API回退、购买或复制认证。官方CLI没有本项目已核实的单一“封闭全部工具”保证；采用官方能力关闭、只读沙箱、临时目录、固定结构化输入及引用校验。固定样本验收只证明本机那次受限调用协议，不证明全部工具隔离或所有业务语义正确。

官方Apollo账期余额不能代替北京时间今日全账号用量，请求ID不能代替实扣回执。因此本版**不能无人值守自动跑完真实1000家付费采集**。逐页人工核实费用是诚实功能边界；若今后获得官方可靠计费/幂等能力，需新增验证才能自动结算。

本次没有权限扩大、服务采购、仓库公开性修改、邮件功能或真实千家公司采集。此前GitHub Release预检Forbidden，本轮按要求未重试且未创建Release；交付通过仓库ZIP及可用的Library上传提供。
