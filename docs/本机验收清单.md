# 用户回来后的最小操作

今晚电脑保持关闭即可。云端代码、模拟和包检查已完成；以下确实需要本机或本人账号。

1. 完整解压 v1.1.0，安装Python 3.12 64位（若已有可跳过），双击安装、启动。创建模拟任务目标15，导出Excel应为16家合格公司、16个邮箱；测试暂停后关闭窗口，重新启动仍暂停。
2. 按 [Codex官方核对](Codex订阅接口核对.md) 安装官方CLI，双击登录Codex，用本人ChatGPT登录；在连接状态明确运行固定合成材料订阅验收。此步骤用订阅额度，不用模型API，不购买服务。Windows原生沙箱/版本不支持时停止并处理具体原因。
3. 若已有Apollo API权限，输入本机密钥并做免费健康检查；确认现有套餐、积分单位、单页费用上界、全账号北京时间用量及可核对实际扣费的依据。健康检查不是搜索权限或计费验收。
4. 先导入历史表，再在届时有效授权下进行少量真实试采，逐页对账；人工核对主体、业务、邮箱和来源页面。只有实际验收通过才能进入真实1000家任务。

不需要写代码、审源码、提供认证文件或开启云端常驻服务。缺权限时程序应暂停，不能换账号、购买额度或绕过限制。真实付费试采不在本次开发授权内，本轮未执行。

Windows仍需确认：CMD编码/中文与空格路径、浏览器自动打开、Excel本机打开、单实例和暂停恢复；云端仅做静态与Linux特殊路径实际检查。Python/CLI首次安装可能需本人系统安装权限。

真实Apollo仍需确认：已有API功能权限、当前方案计费和每页上界、实际扣费核对途径。官方接口未提供已核实的逐动作实扣/幂等恢复保证，当前逐页人工对账是明确功能限制，不能称为只欠登录。

真实网页/订阅仍需确认：地区网络、TLS/网页访问、静态官网取证质量、本人订阅调用与限额、业务/主体/邮箱审核准确性。固定样本通过不能代替真实样本验收，更不等于投递验证。

升级旧版：关闭旧程序，备份整个旧data，再将data复制到新解压目录；只运行一个副本。数据库迁移保留任务与历史；旧真实任务没有固定搜索设置时需新建任务，原记录保留。遇到错误提供诊断文字和任务ID，不提供密码、API密钥、auth.json或Cookie。
