# v1.2.0 本机最小验收清单

今晚电脑保持关闭即可。代码和模拟检查在云端完成；下面只保留需要 Windows、本人账号或真实网络的操作。无需编程、审源码、提供认证文件或开启云端常驻服务。

## 先检查启动和订阅

- 完整解压 v1.2.0。首次安装 Python 3.12 64 位，双击“安装.cmd”“启动.cmd”。检查中文/空格路径、浏览器自动打开、Excel 可打开、重复启动被阻止。
- 创建模拟任务目标 15，导出应为 16 家合格虚构公司、16 个唯一邮箱。暂停后关闭窗口再启动，任务应仍暂停；模拟不是实际客户。
- 按 [Codex 官方核对](Codex订阅接口核对.md) 安装 CLI，双击“登录Codex.cmd”，本人用 ChatGPT 登录。在连接状态明确运行“订阅最小验收”。此步骤用现有订阅额度，不用模型 API、不购买服务。
- Windows 10 官方 CLI 是 best effort，需符合官方版本和原生沙箱条件。安装、登录、沙箱或权限失败时，按显示原因处理后重验，不能通过关闭限制放行。固定样本通过仍需检查真实公司审核质量。

## 选择一条候选路径做小样本

| 路径 | 最少需要检查的内容 |
| --- | --- |
| 已有 Apollo 文件 | 导入一份小 CSV/XLSX，确认列映射和来源链接；不要求 Apollo key。确认原件保留、导入邮箱未直接被采纳、官网与运行时 Codex 审核确实完成 |
| 已保存的 Apollo 公司 | 用已有 API 权限做免费健康检查。确认官方费用说明能被程序取得，Codex 辅助评估及代码确认为固定免费端点后读取小样本；不要求收费预算/对账，不切换全库搜索 |
| 全库收费搜索 | 仅在当时有效的本人授权下检查。核实当前非旧版套餐每页最高 1 积分、无附加费，填写真实账户费用证据，确认当日全账号已用量和无账本外支出。先完成 Codex 费用评估及代码门，再运行少量固定条件页面 |

实际免费账户路径、费用文档联网读取和真实订阅联调在本次云端没有验收通过；本轮环境直接读取官方费用文档失败。程序需要在本机取得证据，不能将模拟文本当作免费或收费的证明。文件导入本身不请求 Apollo，但文件在 Apollo 中导出是否收费仍须在其界面确认。

## 核对结果与收费保护

- 人工抽查主体、润滑油业务、邮箱对应公司和来源页面。候选、缺邮箱、不合格及未审核项不能计入目标。公开来源证据不是投递验证。
- 导出公司总表和唯一邮箱清单，回看 URL、时间、核验依据；追溯记录应保留原始行和排除原因。先导入历史，再确认当批与历史重复都被排除。
- 收费小样本中，校验通过的响应应显示“已验证响应，待核实实扣”，实际扣费仍为空；同日有效授权和剩余保守预算允许继续分页，预计超过 50 分必须暂停。
- 对照账户依据逐项核实实扣及北京时间归属日。只有同一授权、同一发生日、已验证且逐项实扣相同的所选动作，才能一次批量对账；其它情况逐项处理。统一标价、预留值或总额平均不能替代实扣。
- 结果未知应冻结新的收费请求；跨日待结清不能被日期切换绕过。缺少当日授权的旧任务不能新收费；旧缓存可恢复。续期应先暂停、等在途请求结束，结清未结动作后核实今日基线，再沿原固定条件授权。

确认小样本、费用与暂停恢复符合预期后，再在当时有效授权下运行目标 1000 的任务。本轮开发没有执行真实收费试采，也没有授权程序自动购买服务。

## 旧版升级

关闭旧程序，备份整个旧 `data`，再复制到新解压目录；只运行一个副本。迁移保留任务、历史、候选和响应。旧任务缺少固定搜索设置时需新建任务；已有固定设置但缺新费用授权时，通过暂停后的续期入口处理，不能直接新增收费请求。

遇到错误提供诊断文字和任务 ID，不提供密码、API key、`auth.json` 或 Cookie。当前版本的实际测试证据见 [第三轮验收报告](第三轮验收报告.md)；[第二轮报告](第二轮验收报告.md) 是历史记录。
