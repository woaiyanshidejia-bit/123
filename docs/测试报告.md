## 浏览器实测

使用云端已安装Chromium 154.0.8037.57和Playwright，实际启动本机HTTP服务器，所有测试浏览器外部请求拦截；`scripts/browser_check.py`通过七页导航、模拟任务、暂停/继续、16合格、Excel下载、只读诊断、预算确认、真实模式未连接暂停、CSRF/Host拒绝。零页面错误，真实合格0，付费动作0。

该测试框架为读取状态使用CSP bypass，已另外运行`scripts/standard_csp_check.py`：**不绕过生产CSP的真实点击流程通过**。对应`artifacts/browser-report.json`和`http-report.json`。没有上传浏览器截图作为交付物。

## Windows与包完整性

`check_windows_package.py`在Linux含中文、空格和 `! % & ( ) ^` 的目录实际新建venv，随包wheel离线哈希安装成功，中文SQLite/XLSX往返成功。见`windows-static-report.json`；这不等于Windows CMD执行通过。

最终ZIP由`scripts/build_package.py`允许列表生成，内含逐文件SHA256 manifest；`scripts/package_check.py`对ZIP完整解压、校验每个文件及禁止项、在新venv离线按哈希安装、重新运行全部193项测试。该检查结果与最终ZIP哈希写入仓库的`artifacts/package-report-v1.1.0.json`，日志为`offline-install-output-v1.1.0.txt`；它们在最终ZIP生成后产生，避免自引用哈希，不写入该ZIP。
